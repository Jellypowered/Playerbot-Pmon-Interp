How to read this PMON export

Time per tick is category time divided by recorded PlayerbotAIBase::FullTick calls. Use it to rank steady cost per bot update.

Calls / tick follows trigger/value scheduling. High frequency can be intentional: trigger and value check intervals control how often code is evaluated.

FullTick time is cadence, not CPU cost. Its scope is completed at the next UpdateAI call, so use AI time / tick and operation timing for work cost.
